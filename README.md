# Домашнее задание к лекции «Создание REST API на FastApi» (Часть 2)

## Описание проекта
Проект доработан в соответствии с требованиями второй части задания. Добавлена ролевая модель (RBAC) и авторизация через JWT-токены.

## Архитектура проекта
Проект разделен на слои для удобства поддержки и масштабирования:
- `main.py` — точка входа, подключение роутеров.
- `schemas.py` — Pydantic-модели для валидации данных.
- `auth.py` — логика JWT (генерация, проверка), хеширование паролей, зависимости для проверки прав.
- `database.py` — "база данных" в памяти.
- `routers/` — папка с эндпоинтами (`users.py` для пользователей, `ads.py` для объявлений).

## Реализованный функционал и права доступа

### Аутентификация
- **POST /login** — возвращает JWT-токен (срок действия 48 часов). При неверных данных возвращает 401.

### Пользователи (роли: `user`, `admin`)
- **POST /user** — создание пользователя (доступно без токена).
- **GET /user/{user_id}** — получение по ID (доступно без токена).
- **PATCH /user/{user_id}** — обновление (только сам пользователь или админ).
- **DELETE /user/{user_id}** — удаление (только сам пользователь или админ).

### Объявления
- **POST /advertisement** — создание (только авторизованные `user` и `admin`).
- **GET /advertisement/{advertisement_id}** — получение (доступно без токена).
- **GET /advertisement?{query_string}** — поиск (доступно без токена).
- **PATCH /advertisement/{advertisement_id}** — обновление (только владелец или админ).
- **DELETE /advertisement/{advertisement_id}** — удаление (только владелец или админ).

## Как запустить локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите сервер: `uvicorn main:app --reload`
3. Документация: `http://127.0.0.1:8000/docs`

## Как запустить в Docker
1. Соберите образ: `docker build -t fastapi-shop .`
2. Запустите: `docker run -p 8000:8000 fastapi-shop`
